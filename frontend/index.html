Features

不只给结论，更给可复核的依据

核查助手最容易「一本正经地编造」。核真把纪律写进架构：判断必须来自工具返回的数据，数据查不到就明说。

⊞

多工具交叉查证

一条传闻涉及几家就查几家：行情 get_quote、公告 get_announcements、资讯 get_news 逐一比对，矛盾点直接指出。

✓

三档判断 + 置信度

可信 / 存疑 / 无法核实三档结构化输出，附置信度分值；低于阈值自动悬起，绝不硬编结论。

⚖

人工审批队列

低置信度操作（如接入外部数据源）进入审批队列，显示影响范围与理由，批准 / 拒绝 / 编辑皆可，5 秒内可撤销。

◈

计划先行执行

先拆解传闻生成执行计划，再逐步查证；每步状态（Done / Running / 待审批）实时可见，可拖拽调整。

◔

置信度可视化

进度条 + 环形图按状态着色：高置信绿色、中置信橙色、低置信红色，风险一眼可辨。

🗂

全程留痕可复核

完整轨迹回放、工具调用原始输入输出、AI 协作记录导出——每个判断都能追溯到具体数据。

How it works

四步，从传闻到结论

1

拆解识别

解析传闻主张，识别涉及的全部公司，拆成可查证的事实点。

输入：1 条传闻 → 输出：N 家公司
2

工具查证

逐家调用行情 / 公告 / 资讯工具，交叉比对，记录原始返回。

get_quote · get_announcements · get_news
3

结构化判断

输出可信 / 存疑 / 无法核实 + 置信度 + 证据 + 数据来源。

判断必须能复核到具体数据
4

留痕归档

核查报告 + 结构化表格 + 完整轨迹，供人工复核与回放。

核查报告.md · 传闻核查表.csv
Verdict system

三档判断，全站一套颜色语言

绿色可信、橙色存疑、灰色无法核实、蓝色待审批——在工作台、报告、看板中含义完全一致。

可信TRUSTED · 绿

传闻主张与工具查到的数据一致，证据链完整。

例：恒润科技涨停 +10.0%，龙虎榜两机构净买入 → 「大资金进场」可信（96%）
存疑SUSPECT · 橙

传闻与官方公告或行情数据直接矛盾，倾向不实但保留判断空间。

例：公告「三期临床达到主要终点」vs 传闻「临床失败」→ 存疑（92%）
无法核实UNKNOWN · 灰

本地数据查不到相关信息。明说查不到，绝不编造——这是底线。

例：「国资重组」仅查到业绩预告，无重组信息 → 无法核实（12%）
